# Инструкция для лидеров: CRM, соцвходы и боты

## Вход в CRM

1. Вход выполняется по логину и паролю, а не по почте.
2. Логин создается из почты при создании пользователя: `msadakov@yandex.ru` становится `msadakov`.
3. Почту и логин можно менять в разделе **Моя учетная запись** (`/profile`).
4. Яндекс ID и VK ID нужно сначала привязать там же. После привязки можно входить через соответствующую кнопку на странице входа.
5. Если к учетной записи привязана пастырская карточка, она открывается из того же раздела. Адрес из Яндекс ID подставляется в карточку человека при привязке (если поле адреса было пустым) или вручную на странице карточки.

## Привязка ботов (Max / VK / Telegram)

1. Откройте **Моя учетная запись**.
2. В блоке `Боты уведомлений` нажмите **Привязать Max** (или VK / Telegram, если канал настроен).
3. Откроется мессенджер по deep link со встроенным одноразовым кодом:
   - **Max:** `https://max.ru/<бот>?start=КОД` — привязка при старте бота (`bot_started`).
   - **Telegram:** `https://t.me/<бот>?start=КОД` — привязка командой `/start КОД`.
   - **VK:** `https://vk.me/<сообщество>?ref=КОД` — после перехода отправьте боту любое сообщение (VK передаёт `ref` только с первым сообщением).
4. Бот ответит, что канал привязан. Уведомления будут приходить в этот личный чат.
5. Не пересылайте одноразовую ссылку/код в общий чат: она действует 30 минут и привязывает канал к вашему аккаунту.

Запасной способ (если deep link недоступен): отправьте боту `привязать КОД` вручную.

## Что можно делать из чата

- Нажимать быстрые действия из пастырского напоминания: `позвонил`, `написал`, `назначил встречу`, `нужна помощь пастора`.
- Отправить короткий отчет после встречи: `отчет: Встреча прошла тепло, было 9 человек, нужен повторный контакт с новичком`.
- Сохранить молитвенную нужду: `молитва Иван Кузнецов: нужна поддержка по работе`.
- Создать заявку новичка: `новичок Анна Петрова; +79990000000; Серебрянка`.
- Если новичок отправляет геопозицию боту, CRM подберет домашнюю группу по координатам и загрузке.

## Правила безопасности

- Персональные детали не отправляются в групповые служебные чаты.
- В групповых уведомлениях пишется только факт: например, группа просит помощи пастора.
- Подробности открываются по ссылке в CRM после авторизации.
- Молитвенные нужды и пастырские заметки пишите в личный бот-чат или в CRM, не в общий чат группы.

## Для областных лидеров, пасторов и администраторов

- Следите за ежедневной сводкой рисков: люди без контакта, группы с просьбой о помощи, группы с пониженной активностью.
- Обрабатывайте заявки новичков на странице `Люди -> Заявки участников`.
- Если в заявке есть рекомендованная группа, проверьте вместимость и район перед созданием карточки.
- Карточка другого пользователя (`/user?id=`) — для управления чужими учетными записями. Своя учетная запись всегда открывается как `/profile`.
- Настройте реальные переменные окружения для OAuth и ботов только в production-окружении (`bots.max.*`, `bots.vk.*`, `bots.telegram.*` в `config/local.php`).
